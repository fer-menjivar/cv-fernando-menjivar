# Portfolio - Fernando Menjivar

Minimalist portfolio built with **Astro** and **JSON Resume**. Designed to be fast, responsive, and easy to maintain.

## 🚀 Features

- **Responsive Design**: Optimized for all devices.
- **Dark Mode**: Support for light and dark themes.
- **Typed Data**: Uses TypeScript for better development experience.
- **JSON Resume**: Data driven architecture using `cv.json`.
- **Keyboard Navigation**: Enhanced accessibility with `hotkeypad`.

## 🛠️ Tech Stack

- [Astro](https://astro.build/) - Web framework.
- [TypeScript](https://www.typescriptlang.org/) - Typed JavaScript.
- [JSON Resume](https://jsonresume.org/) - Standard for resumes.
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) - Vanilla CSS styling.

## 📦 Installation

To get started locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/fer-menjivar/cv-fernando-menjivar.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:4321`.
